1. A four-node flow looks aligned on a desktop but drifts on a phone. Which repair matches the component contract?

  • A. Put the connector on the following node and let one gap value size both spaces

    Correct. The following node owns both its connector glyph and the exact space that contains it.

  • B. Add a narrower connector column beside each node at the phone breakpoint

    Not quite. A sibling connector retains a separate alignment box, so the original drift remains possible.

  • C. Reverse the ordered list whenever the available width falls below the desktop threshold

    Not quite. Reversing the list changes semantic reading order rather than repairing the connector geometry.

  • D. Keep the desktop row whenever the browser viewport remains wider than the report column

    Not quite. A figure can be narrow inside a wide viewport, so its own container must decide.

2. A script is blocked by the report viewer. Which authored sequence still transfers all of its information?

  • A. One whose later steps start hidden and depend on a Next control to reveal them

    Not quite. Blocking the script would strand every hidden step and leave a dead control behind.

  • B. One authored as a complete ordered list whose optional controls are created at runtime

    Correct. The native document contains the entire sequence, while enhancement changes only how it is traversed.

  • C. One that replaces blocked interaction with a sentence asking readers to enable scripts

    Not quite. A warning cannot substitute for the missing states and explanations the sequence was meant to teach.

  • D. One that assumes reduced-motion users always have scripts available for state changes

    Not quite. Motion preference and script execution are independent capabilities, so neither can guarantee the other.

3. A figure caption repeats the paragraph immediately above it word for word. What learning problem does that create?

  • A. It strengthens signaling because every important sentence should appear in two adjacent places

    Not quite. Repetition consumes attention but adds no new relationship between the visual and the prose.

  • B. It affects visual polish only because captions do not participate in the explanation

    Not quite. The caption carries the figure's claim and is part of the durable teaching argument.

  • C. It defeats dual coding because the second channel contributes no additional explanatory structure

    Correct. A useful figure and caption should reveal a relationship that prose alone did not already convey.

  • D. It proves the paragraph should be deleted even when it supplies evidence absent from the figure

    Not quite. The repair is to separate roles, keeping evidence in prose and a distinct claim in the caption.

4. A reviewer says the tests establish an author's motive, but the repository records only behavior. How should the report respond?

  • A. Present the motive as fact because it explains the observed implementation cleanly

    Not quite. Plausibility does not turn an interpretation into evidence recorded by the repository.

  • B. Delete every interpretation because durable reports may contain repository facts only

    Not quite. Interpretation can aid understanding when it is clearly marked and bounded by what remains unknown.

  • C. Infer the motive from passing tests because a green witness explains why code was written

    Not quite. Tests establish selected behavior under their conditions, not the private intention behind the design.

  • D. State the observed behavior as fact and label the motive as an interpretation or limit

    Correct. Readers can use the interpretation without mistaking it for something the available evidence proves.

5. A narrow comparison table is hard to scan. Which change preserves both accessibility and exact cell relationships?

  • A. Turn every table row into an independent block card at the mobile breakpoint

    Not quite. Replacing table layout can destroy the header relationships assistive technology uses to interpret cells.

  • B. Reduce the entire table font until all columns fit inside the phone viewport

    Not quite. Tiny text transfers the layout problem to the reader and can make the evidence unreadable.

  • C. Keep the semantic table and place horizontal overflow on a labeled keyboard-focusable wrapper

    Correct. The wrapper handles narrow geometry while scoped headers and native table structure remain intact.

  • D. Remove the least favorable comparison column whenever the available width becomes narrow

    Not quite. Hiding the limiting evidence changes the claim instead of making the same comparison accessible.
